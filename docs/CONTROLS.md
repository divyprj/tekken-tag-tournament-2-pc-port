# Input Configuration and Keybindings Guide

This guide covers all input configurations for the Tekken Tag Tournament 2 PC port, including gamepad setups, keyboard mapping, and arcade stick configurations.

---

## The Tekken Button Layout Architecture

Tekken uses a four-button combat layout corresponding to individual limbs:
- 1: Left Punch (LP) - Xbox X button / PlayStation Square
- 2: Right Punch (RP) - Xbox Y button / PlayStation Triangle
- 3: Left Kick (LK) - Xbox A button / PlayStation Cross
- 4: Right Kick (RK) - Xbox B button / PlayStation Circle

In Tekken Tag Tournament 2, a dedicated Tag button is mapped to Right Bumper (RB).

## Default Keyboard Configuration

The default keyboard layout provided out of the box is configured as follows:

| In-Game Action | Xbox Controller Equivalent | Default PC Key |
|---|---|---|
| Up / Jump | D-Pad Up | Up Arrow |
| Down / Crouch | D-Pad Down | Down Arrow |
| Left / Walk Back | D-Pad Left | Left Arrow |
| Right / Forward | D-Pad Right | Right Arrow |
| Left Punch (1) | X Button | Z |
| Right Punch (2) | Y Button | X |
| Left Kick (3) | A Button | A |
| Right Kick (4) | B Button | S |
| Tag Button | Right Bumper (RB) | W |
| Throw / 1+2 | Left Bumper (LB) | Q |
| Tag Assault / 1+4 | Left Trigger (LT) | E |
| Tag / 3+4 | Right Trigger (RT) | R |
| Pause / Menu | START | Enter or Space |
| Cancel / Select | BACK | Backspace |

## Tekken 7 PC Standard Layout (WASD + UIJK)

Most modern PC fighting game players prefer the standard layout popularized by Tekken 7 on Steam:

### Movement (Left Hand)
- W: Up / Jump
- A: Left / Backdash
- S: Down / Crouch
- D: Right / Forward

### Combat (Right Hand)
- U: Left Punch (1)
- I: Right Punch (2)
- J: Left Kick (3)
- K: Right Kick (4)
- O: Tag Button (RB)
- L: 1+2 Macro (LB)
- P: 1+4 Macro (LT)
- Space: Tag or 3+4 Macro (RT)

### How to Apply in the Game
1. Launch the game and press Enter on the title screen.
2. Navigate to `OPTIONS > CONTROLLER SETUP`.
3. Highlight `BUTTON SETTINGS` and press Left or Right Arrow to change the mode from `PAD` to `KEYBOARD`.
4. Select each action on screen and press your desired replacement key.
5. Confirm and exit. The game automatically saves your custom configuration into your profile directory at `%LOCALAPPDATA%\TTT2Recomp\`.

## Arcade Sticks and Hitbox Layouts

### XInput Fightsticks
All official Xbox 360, Xbox One, and Xbox Series X|S arcade sticks function natively with zero driver setup.

### PlayStation Fightsticks
For Sony DualShock, DualSense, or PS3/PS4/PS5 arcade sticks, ensure Steam Input is enabled or use DS4Windows to translate inputs to standard XInput.

### All-Button / Hitbox Layout
For keyboard players simulating a Hitbox controller:
- Left: A
- Down: S
- Right: D
- Up / Jump: Space
- Attack buttons: U, I, O (top row) and J, K, L (bottom row)
This layout allows precise directional execution and instant Korean backdashes without thumb fatigue.
